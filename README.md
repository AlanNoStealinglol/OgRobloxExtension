# Roblox++ 

A simple browser extension that changes Roblox Back To OG!

## Installation

### Chrome / Edge
1. Download this repository (Code > Download ZIP)
2. Extract the ZIP file
3. Open Chrome/Edge and go to `chrome://extensions` or `edge://extensions`
4. Enable "Developer mode" (toggle in the top-right corner)
5. Click "Load unpacked" and select the extracted folder
6. The extension should now be installed and active

### Firefox
1. Download this repository (Code > Download ZIP)
2. Extract the ZIP file
3. Open Firefox and go to `about:debugging#/runtime/this-firefox`
4. Click "Load Temporary Add-on..." and select the `manifest.json` file from the extracted folder
5. The extension should now be installed and active (note: this installation is temporary and will be removed when Firefox closes)

## How It Works

It changes many features such as:

1. Changes Play Button to Green (It works with ropro by the way)
2. Changes Communities to Groups!
3. Changes Charts to Games!
4. Many more.

## Notes

- You may need to refresh Roblox pages that were already open before installing the extension
- If the navigation bar doesn't update immediately, try refreshing the page
